# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

# Windows get started:
```
scoop bucket add versions
scoop install main/neovim main/git main/zig main/ripgrep main/fd main/fzf main/tree-sitter main/7zip main/curl main/luarocks versions/lua51 extras/lazygit extras/vcredist2022
git clone git@github.com:rdelian/lazyvim.git $env:LOCALAPPDATA\nvim
nvim
```
